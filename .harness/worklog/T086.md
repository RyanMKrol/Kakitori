# T086: Fix numeric fields in Settings that can't be cleared

## Summary
Fixed the issue where the 'New cards per day' and 'Max reviews per day' fields in Settings would immediately refill after being cleared, preventing users from typing new values.

## Changes Made
**File: Sources/Features/Settings/SettingsView.swift**

Modified two `.onReceive(Just(...))` blocks to gate the refill-on-empty logic with a focus check:

1. **New cards per day field (line 51-55):**
   - Before: `if newCardsText.isEmpty { ... }`
   - After: `if newCardsText.isEmpty, focusedField != .newCards { ... }`

2. **Max reviews per day field (line 84-88):**
   - Before: `if maxReviewsText.isEmpty { ... }`
   - After: `if maxReviewsText.isEmpty, focusedField != .maxReviews { ... }`

### Why This Fixes the Issue
- Previously, `Just(newCardsPerDay)` would fire on every body re-render
- Clearing the text triggered a re-render, which immediately refilled the field
- The focus check prevents refilling while the user is actively editing
- The existing `commitNewCardsValue()` and `commitMaxReviewsValue()` functions still handle validation/clamping on blur/submit
- No other Settings behavior was changed
