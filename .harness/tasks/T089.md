## Overview
Introduce the shared building blocks that both Free Study entry-point changes (ideas #2 and #3) consume: a BLUE colour token in KakitoriTheme (Sources/Support/Theme.swift) for the Start Free Study button, and a single shared label constant for the feature's on-screen name so the deck-setup button, the Summary button, and the running-session badge all read identically. This unit only adds tokens/constants; the views that use them ship in fsep-b and fsep-c.

## Do

Make it a blue that is clearly distinct from the red `accent` and legible on both light and dark `paper` (use a dynamic UIColor like the `paper`/`surface` tokens do if a single fixed blue does not read well in both appearances; a mid-blue around RGB (40,110,210) light is a reasonable default — see the pending label/colour questions, swap the exact value if a specific blue is chosen). Also add a single shared label constant for the feature's name — add `public static let freeStudyLabel = "Free Study"` to KakitoriTheme (this is the current on-screen wording; if the label answer is "Endless Study", change only this value). Keep everything in Theme.swift so no other file is touched by this unit.
