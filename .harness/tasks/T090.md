## Overview
Idea #2. When a deck's daily study is already done (dueCount == 0), surface the caught-up state INLINE on the DeckSetupSheet before the user commits to starting, and remove the separate full-screen "All caught up" interstitial ENTIRELY. In the caught-up variant the sheet shows a heading like "All study done for the day." plus smaller secondary text like "You've already completed your study for the day. This is an endless practice run.", and the primary button becomes a BLUE "Start Free Study" button (KakitoriTheme.freeStudyAccent, label from KakitoriTheme.freeStudyLabel = "Free Study"). IMPORTANT (owner decision): Free Study is NOT its own writing mode — it only decouples the session from SRS inputs/outputs. The practice-mode picker (Trace / Listen and Write / Translate and Write / Mixed) STAYS VISIBLE in the caught-up state, and tapping Start Free Study launches an endless Free Study session in the currently SELECTED mode. So all writing modes still apply in Free Study; the only difference from a normal session is that Free Study reads/writes no CardSchedule and no DailyStats.
